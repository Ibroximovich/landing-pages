# Biznes Landing Page Shabloni

Bu shablon — **zamonaviy va professional Business / Agency** landing page. Uni osonlikcha o‘zingizga moslashtirib ishlatishingiz mumkin.

## Shablonni qanday o‘zgartirish kerak? (Oddiy ko‘rsatma)

### 1. Matnlarni o‘zgartirish
1. `index.html` faylini oching (VS Code yoki oddiy Notepad bilan)
2. Ctrl + F tugmasini bosing
3. O‘zgartirmoqchi bo‘lgan matnni qidirib toping va o‘zingizga moslab yozing.

**Muhim joylar:**
- **Kompaniya nomi** → "Biznes Studio" ni o‘zingizning nomingizga almashtiring
- **Hero sarlavha** (eng katta matn)
- **Xizmatlar tavsifi**
- **Telefon raqami** va **Telegram** havolasi
